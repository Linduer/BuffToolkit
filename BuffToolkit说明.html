一、这是什么

一个 exe，所有功能都在浏览器界面里点。双击 BuffToolkit.exe 会启动一个只在本机的网页服务（127.0.0.1，外部访问不到），并自动打开浏览器。

左侧页面 干什么
首页 一眼看订阅 / 账户 / 发信状态，六个功能入口，最近跑过什么
炼金期望计算 实时拉价按利润率筛配方，勾选后直接写进台账
材料邮件提醒 材料到价提醒 + 期望校验：阈值、间隔、时刻表、收件人、立即执行
库存记录 Steam 库存同步、离线查询、缺料分析、材料核对、买卖记录、导出客户版
开炉工具 配料寻优（这炉怎么配）+ 主材料调价（主价改了重算副价）
订阅管理 密钥激活、到期时间、本月剩余炼金次数
配置管理 账户与 Cookie、邮箱与分发、原始 JSON

基本操作约定

  • 双击 exe → 浏览器自动打开（默认 http://127.0.0.1:8377；端口被占会自动往后找，黑窗口里会打印实际地址）
  • 黑窗口别关：它就是服务本体，关掉页面立刻打不开（平时最小化扔一边就行）
  • 重复双击 exe 不会打架：检测到已在运行，只会再开一个浏览器标签页
  • 页面里改的东西点「保存」就写进 爬虫配置.json，立即生效，不用重启
  • 长任务（计算 / 扫描 / 校验 / 同步 / 寻优）在后台跑，页面里实时刷日志，右上角有「停止」按钮；关掉浏览器标签任务也会继续，回首页「最近任务」看进度
  • 同一个任务不能同时跑两个，重复点会提示「正在运行中」
  • 顶栏右边常显订阅状态（到期 / 本月剩余次数），未激活时点它直接跳订阅管理
  • 浏览器白屏、或页面提示「服务连接失败」→ 多半是黑窗口被关了，重新双击 exe
提示老的控制台菜单还保留着（BuffToolkit.exe --cli），功能与页面一致，只有排查问题和做计划任务时才用得到。下面所有操作都走浏览器。

二、第一次用：四步走

提示顺序：① 激活订阅 → ② 加账户、抓 Cookie（必须）→ ③ 配邮箱（要收邮件才需要）→ ④ 填台账（配方数据）。 每做完一步都能回页面看状态，不用一次全做完。

2.1 激活订阅（订阅管理页）

密钥是购买时卖家发的一段 BT- 开头的字符，整段保存好（换机器重装还要用它重新激活）。

  1. 双击 BuffToolkit.exe，浏览器打开后点左侧「订阅管理」。
  2. 把密钥整段粘进输入框（前后带空格没关系，程序会自动去掉）。
  3. 点「激活 / 更换密钥」→ 顶部弹出「激活成功：xxxx 到期」。
  4. 上方卡片显示出 持有人 / 到期 / 本月炼金次数剩余 n/m 即完成。

怎么确认激活成功

  • 顶栏右侧状态条：已激活 · 持有人 · xxxx 到期 | 本月炼金剩余 n/m
  • 到期前 3 天，日期会变黄提醒
  • 订阅管理页的「订阅状态」卡片同样三项

三个概念

  • 到期时间：到期后所有功能被锁，续费拿新密钥按上面同样三步重新激活。
  • 本月炼金次数：只有「炼金期望计算」扣一次（服务端联网计数，改系统时间刷不了）；价格提醒、期望校验、库存同步、配料寻优都不扣。
  • 没网也能用：48 小时会话缓存 + 7 天离线宽限，连续断网超 7 天需联网恢复一次。

2.2 添加账户 + 抓 BUFF Cookie（配置管理页）

账户名就是台账的 sheet 名，一个账户对一个 Steam 号。先建账户，再贴 Cookie。

第 1 步：加账户

  1. 左侧「配置管理」→ 卡片「账户与凭据」→ 点「＋ 添加账户」。
  2. 填「账户名」，如 客户1（唯一、不能含 /，建议就用台账里那个名字）。
  3. 「悠悠 Token」不用悠悠就留空；「SteamID64」不确定就留空（程序默认按账户名对号）。
  4. 「BUFF Cookie」先空着，抓到再回来贴 → 点「保存」。
  5. 表格里出现该账户，BUFF 一列显示「未填」。

第 2 步：在浏览器里抓 Cookie

⚠️ 注意只能在电脑浏览器上操作，手机抓不了。Cookie 等同于你的登录凭据，不要发给任何人。 只用 Steam 通道同步库存的话可以先跳过；但价格提醒、买卖记录、炼金期望计算仍必须配 Cookie。
  1. 浏览器（Chrome / Edge 均可）打开 https://buff.163.com，确认已登录（右上角能看到你的头像）。
  2. 按 F12 打开开发者工具（部分笔记本要按 Fn + F12）。
  3. 顶部点 Network（网络） 标签页（Edge 中文界面叫「网络」）。
  4. 按 F5 刷新页面，列表里会冒出很多条请求。
  5. 点列表中任意一条请求（点第一条最省事）。
  6. 右侧选 Headers（标头） → 往下找 Request Headers（请求标头） 分组。
  7. 找到 cookie: 开头那一行（很长、折成好几行是正常的）：
  8. Chrome：右键该行 → Copy value
  9. Edge：右键该行 → 复制值
  10. 注意复制的是冒号后面那整串，不含 cookie: 这个词。

第 3 步：贴回页面

  1. 回「配置管理」→ 账户表格里该行点「编辑」。
  2. 把整条 Cookie 粘进「BUFF Cookie」框 → 点「保存」。
  3. 表格 BUFF 一列变成「可用」即填对；显示「未填」说明还是空或占位符。

第 4 步：验证凭据真能用

去「库存记录」页 → 「同步库存 · Steam 通道」需要先登录 Steam；只想验 Cookie 的话去「买卖记录 · BUFF 通道」拉一次，能出记录就说明 Cookie 有效。

常见疑问

问题 解答
复制出来太长/带换行 正常，整条原样粘贴即可，不要删减
Cookie 多久过期 不固定（通常数周）；失效时会收到「催更」邮件，或运行日志里提示预检未过
怎么换新 Cookie 重抓一次，「配置管理」→ 该账户「编辑」→ 只替换 Cookie → 保存
多个 Steam 号怎么办 「＋ 添加账户」再来一个，每个填自己的 Cookie；账户名不能重复
浏览器看着登录正常，程序说失效 正常——BUFF 只对行情接口校验登录态，首页不校验；以程序判断为准
悠悠 Token 要不要填 只跑 BUFF 可以空着；要用悠悠比价才需要（Token 各号通用，找卖家要）

2.3 配置收发邮箱（配置管理 → 邮箱配置）

提示只有要收「降价提醒 / 期望校验」邮件才需要配，Cookie 抓完可以先跳过。 程序用「发件邮箱 + 授权码」登录 SMTP 发信，授权码不是邮箱登录密码，要到邮箱里单独生成。

第 1 步：生成授权码（按你的邮箱二选一）

QQ 邮箱（smtp.qq.com，端口 465，可保持默认）

  1. 电脑浏览器登录 https://mail.qq.com
  2. 右上角 设置 → 账户
  3. 页面往下滚，找到 「POP3/IMAP/SMTP服务」 区块
  4. 勾选开启 「IMAP/SMTP服务」（开 POP3/SMTP 也行）→ 按提示用手机 QQ 扫码或发短信完成验证
  5. 开启成功后，同一区块点 「生成授权码」 → 再做一次手机验证
  6. 页面显示一串 16 位字母授权码（只显示这一次）→ 立刻复制保存

163 邮箱（服务器要改成 smtp.163.com）

  1. 电脑浏览器登录 https://mail.163.com
  2. 右上角 设置 → POP3/SMTP/IMAP
  3. 勾选开启 「IMAP/SMTP服务」 → 按提示手机验证
  4. 同页面找 「授权码管理」 → 新增授权码 → 手机验证
  5. 复制生成的授权码保存

第 2 步：回页面填

「配置管理」→ 卡片「邮箱配置」，五个框：

框 填法
SMTP 服务器 QQ 邮箱保持 smtp.qq.com；163 填 smtp.163.com
端口 默认 465（SSL），不用改
发件邮箱 刚生成授权码的那个邮箱地址
授权码 粘贴刚才复制的授权码
默认收件邮箱 提醒发到哪；留空 = 发给发件邮箱自己

再往下两个开关（勾选 = 开启）：

  • 材料降价提醒邮件：价格提醒扫到低于指导价就发
  • 期望校验邮件：台账期望跌破阈值 / 缺价时发预警

填完点 「保存邮箱配置」。

第 3 步：按账户分发（多客户才需要）

同一个邮箱要给不同客户发不同的信：

  1. 「邮箱配置」卡片下方「按账户分发」区，左边填账户名、右边填收件邮箱 → 点「添加」→ 再点「保存邮箱配置」。
  2. 账户名必须和「账户与凭据」里的 账户名、台账 sheet 名一字不差，否则分发不生效（会退回默认收件邮箱）。
  3. 不需要了，右侧「删」掉即可。

第 4 步：验证链路通不通（不真发信）

左侧「材料邮件提醒」→ 卡片「立即扫描（价格提醒）」→ 勾上 「试跑（只扫描看结果，不发邮件）」 → 点「立即扫描」→ 日志末尾出现「邮件正文预览」就说明能发。

首页「运行状态」里的「发信配置」显示「就绪」，也代表五项必填都齐了。

提示Cookie 失效的「催更」信不受两个开关键控制，始终发送（这是凭据维护信号，别关）。

2.4 填台账（实时炼金配方.xlsx 怎么填）

台账是所有功能的数据底座：价格提醒按它的指导价判断命中、期望校验拿它 E 列当基准、缺料分析 / 材料核对按它列的武器找货、炼金期望计算筛完也会往里写。它就是一个普通 Excel 文件，两种形态：

文件 形态 用途
实时炼金配方.xlsx 你的真实台账 程序读的就是它；第一次可以直接改它
实时炼金配方_模板.xlsx 表头 + 一条填好的示例 + 详细填写说明（2 个 sheet） 格式参考，照它建新账户 sheet

数据来源两条路：手工照模板填，或在「炼金期望计算」页算完 → 勾选配方 → 写入台账（组号自动取全表最大值 +1）。

表结构：一个 sheet = 一个账户

  • sheet 名必须与「配置管理」里的账户名、按账户分发的键一字不差（三处对齐，否则邮件发错人）
  • 一个 sheet 里一行行摞着放配方；列固定 18 列

18 列逐列说明

列 填在哪一行 含义 / 谁在读
A 编号 配方首行 组号，同配方内沿用（写入台账时自动递增）——是组号，与收藏品编号无关
B 名字 配方首行 给配方起的名，如 3核子+7寒带
C 级别 配方首行 材料级别，如 军规级（只在子块首行填）
D 买入 配方首行 你的实际买入成本（10 把合计）
E 期望 配方首行 台账期望值——期望校验拿实时期望跟它比，跌破阈值发预警
F 配比 收藏品块首行 本块拿几把，如主块 3、副块 7（同一配方各块合计 10 把）
G 收藏品 收藏品块首行 该块收藏品名，如 核子危机（没有它该块会被跳过）
H 价格 收藏品块首行 该收藏品指导价——价格提醒拿当前价跟它比，低于即命中
I 磨损区间 每行材料 归一化区间 a-b，如 0-0.75（0 = 崭新出厂，1 = 战痕累累）
J 实际磨损 每行材料 该材料的磨损值（0~1），程序取各行中位数当本块归一磨损
K~P 武器1~6 每行材料 材料名，格式 武器 \| 皮肤，不带 (久经沙场) 这类磨损档后缀；一行可并列多把（放不下的换明细行）
Q 产物磨损 收藏品块首行 产物归一化磨损（算产物实际磨损的基准）；留空时程序按「Σ(块目标磨损×配比)/10」自己算
R 主/副 收藏品块首行 主块填 主3、副块填 副7（主/副 开头即可，后面的数字是给人看的）

上面这条就是随包 实时炼金配方_模板.xlsx 里填好的那条示例，照着它的样子往下填即可。

  1. 一个配方 = 主块 + 空 1 行 + 副块，各块「配比」加起来 = 10 把材料（例：3 + 7）
  2. 每块第一行（组头行）填：编号 / 名字 / 级别 / 买入 / 期望 / 配比 / 收藏品 / 价格 / 产物磨损 / 主副
  3. 组头行以下的明细行只填 3 类：磨损区间、实际磨损、武器1~6
  4. 空 1 行 = 换收藏品块（同配方）；空 2 行及以上 = 开新配方——程序靠空行数分配方，别乱空

编辑注意

  • 改台账前先别跑程序（文件被 Excel 占着时任务会提示「请先关闭」）
  • 保存即生效，下次运行重读，不用重启程序
  • 台账含个人持仓：不随分发包外发

三、七个页面逐个说

3.1 首页

三张卡：

  • 运行状态：订阅状态、账户数（BUFF 可用 n 个）、发信配置是否就绪。缺 爬虫配置.json 时这里会飘黄条提示去配置管理。
  • 功能：六张入口卡，点一下直接跳对应页面。
  • 最近任务：最近 6 条任务的任务名、状态（运行中 / 完成 / 失败(退出码)）、开始时间、结束时间。长任务跑着的时候可以关掉页面做别的事，回头这里看结果。

3.2 炼金期望计算

干什么：按你的门槛条件实时拉 BUFF 数据，算上百个配方的利润率，只留达标的，可以直接写进台账。

怎么跑：「计算参数」卡里六项填好 → 点「开始计算（联网拉价，需要较长时间）」。

字段 填法 例
利润率门槛（只显示高于它的） 想全看填 0.5 1.5
材料等级 下拉选，选项来自参照表的品级页 军规级
主材料把数 a（副材料 = 10 − a） 下拉 1~5，括号里就是副材料把数 4（副 6）
收藏品编号 逗号分隔，至少 2 个，两个一组配对枚举 6,5
两个材料归一化磨损 恰好 2 个，第一个绑主材料、第二个绑副材料 0.0142,0.1071
产物归一化磨损 目标档位上限；输入框下拉给了四档提示 0.07
  • 收藏品编号不用背：输入框下面有折叠的 「收藏品名字 ↔ 编号对照表」，展开后点编号直接填进输入框（点一次加一个）。全量对照表也在附录 C。
  • 产物磨损下拉四档：0.07（崭新）/ 0.15（略磨）/ 0.38（久经）/ 0.45（破损）。填的是归一化磨损，不是皮肤上那个 0.1234。

过程：两三分钟到十几分钟不等（编号越多越久），日志框实时刷；触发 BUFF 风控时程序自己放慢，不用管。每次计算扣 1 次本月炼金次数。

结果怎么读：「计算结果」卡出现表格，一行一个达标组合：

列 说明
# 序号，写入台账时按它勾选
勾选框 表头的框是全选（「缺价格列表」的行不可写，框是灰的）
配方 材料构成简写
利润率 / 总成本 / 总期望 三个数一起看，别只看利润率
写入状态 可写入 / 缺价格列表（有材料没取到价，这种写进台账会算出错）

同时落盘一份 输出\配方筛选\配方_{等级}_a{a}_{磨损}_{时间}.xlsx，日志在 日志\配方筛选\。

写台账（不扣次数）

  1. 勾选要写的配方（表头可全选）。
  2. 勾选目标 sheet（= Steam 号，可多选）。
  3. 点「写入选中的配方到台账」→ 弹确认 → 确定后看下方日志。

组号自动取全表最大值 +1，按主材料分组；写入前建议先确认勾的行对不对，写错了只能手工删行。

提示页面提示「参照表暂不可用」→ 先去「订阅管理」确认订阅有效、联网，然后刷新页面（服务会自己重新拉参照表，不用重启）。

3.3 材料邮件提醒

价格提醒和期望校验都在这一页：上面一张状态卡（发信配置 / 订阅），下面四张操作卡。

卡 1：立即扫描（价格提醒）

  • 勾「试跑（只扫描看结果，不发邮件）」→ 只扫不发，用来验证凭据和邮箱。
  • 不勾 → 真扫真发：按账户拆分收件人，正文含命中清单 + 双低优选（磨损更低且价格更低的按降幅排序）。
  • 手动点按钮等于强跑，不受「扫描间隔 / 时刻表」限制（和定时触发不是一回事）。

扫描干的事：读台账拿到要盯的材料 → BUFF、悠悠两平台并行取价 → 当前价低于指导价（或低于指导价 N%，看降幅阈值）算命中 → 整理成邮件发出去。

提示C5 与 Steam 的价格查询代码已实现，但客户版暂不开放（客户机缺 C5 凭据与签名依赖，Steam 行情没做过现场验证）。客户版只跑 BUFF / 悠悠。

卡 2：价格提醒设置（改完点「保存价格提醒设置」）

项 说明
每天运行时刻 点「＋ 添加时刻」加一行，用时间框选点（滚轮可 ±15 分钟微调）；最多 12 个。填了就按时刻表跑，「扫描间隔」失效
扫描间隔（小时） 距上次跑完不足这个时长就跳过；0 = 不限制，支持 0.5 这类小数
降幅阈值（%） 当前价低于指导价百分之几才算命中；0 = 低于即提醒
无命中也发一封「无」邮件 一件都没命中时，要不要发一封「扫描了什么、都没到价」的汇报

卡片底部显示「上次扫描：xxxx」，它同时是间隔计时和时刻表判断的依据。

提示时刻表只是记录什么时候该跑，真正到点得靠系统计划任务去触发（见附录 B）。没建计划任务的话，就等于只在点「立即扫描」时才跑。

卡 3：期望校验（改完点「保存期望校验设置」）

  • 勾「试跑（不发邮件、不写历史）」→ 只校验打印。
  • 不勾 → 真校验真发信，同样不受间隔限制。
  • 每天校验时刻 / 校验间隔：规则与上面完全一样，两套计时各自独立。
  • 跌破阈值（%）：实时期望低于台账 E 列多少算预警，默认 5。
  • 平安邮件：全部正常也发一封汇总（默认开）。

校验干的事：读台账全部配方 → 逐个拉产物实时价重算期望 → 与 E 列比对 →

  • 预警：跌破阈值或缺价 → 发信（主要就靠这封）
  • 平安邮件：全部正常也发一封汇总
  • Cookie 失效：本轮报告不发（避免把「缺价」当行情问题），只发催更信

每个配方三种状态：正常 / 预警（跌破）/ 缺价；历史趋势存在 期望历史.json（每配方最多留 30 次）。日志在 日志\期望校验\。

卡 4：邮箱与分发

就是个跳转入口，收件人 / SMTP / 授权码 / 按账户分发 / 邮件开关都在「配置管理」页改（同一份配置）。

3.4 库存记录

六张卡，从上到下就是常用顺序。

卡 1：同步库存 · Steam 通道（推荐）

  1. 账户下拉选号，括号里会写明「已登录 Steam」还是「未登录」（登录过的后面还带 steamID）。
  2. 没登录过 → 按钮显示「令牌验证器登录」，点它展开表单：
  3. 填 Steam 账号名（登录名，不是昵称）+ 密码 → 「开始登录」
  4. 页面提示「需要验证码」时，打开手机 Steam App → 右下角菜单 →「Steam 令牌」→ 令牌验证器，把 5 位动态码填进页面 → 「提交验证码」
  5. 动态码 30 秒一换；提示「码不对/已过期」就重取一个新的再提交
  6. 登录成功后按钮变成「同步库存（Steam 通道）」，点一下就拉官方库存再写表，结果与游戏内一致。

  7. 换号或令牌失效 → 点「重新登录」重走一遍；令牌验证器不可用时，卡片底部「扫码登录（备用）」用手机 Steam App 扫一扫（二维码约 5 分钟内有效）。

  8. 密码只用于本次换长期令牌：不保存、不落盘，填完发起后页面里也立刻清掉。

  9. 令牌只存本机（steam_probe\令牌_*.json），只用来读库存，不操作账号。
  10. 结果写 输出\库存\库存记录.xlsx（主存储），另存一份带时间戳的快照。
  11. 合并规则：你手工加的行（assetid 留空）永不覆盖；你改过的行以你为准；库存里已卖出的行自动删除。
  12. 防呆：拿错号的凭据、或接口返回的号与所选账户对不上时会拒写，不会污染别的账户的数据。

卡 2：买卖记录 · BUFF 通道

选账户（只列 BUFF Cookie 可用的）→「拉取买卖记录（BUFF 通道）」。生成 输出\持仓\持仓账本_<时间>.xlsx（每次一份）+ 持仓账本_累计.xlsx（历史总账），含买入笔数/金额、卖出笔数与实收、失败未成交、已平仓盈亏、按月统计。

提示这个通道只拉买卖记录，不拉库存。要用 BUFF Cookie 同步库存得走命令行（附录 A），日常用 Steam 通道就够。

卡 3：查询库存

输入关键词（名字模糊匹配，多个逗号分隔，留空 = 全部）→「查询库存」。离线读上次的快照，不联网，所以必须先同步过一次。

卡 4：分析与账本

两张入口卡，点一下就跑到下方：

  • 缺料分析：对着台账 + 库存算每个配方能凑几份、还差什么材料、缺的被几个配方共用；按缺口从多到少排，最上面就是该买的。
  • 材料核对：台账材料 vs 库存覆盖情况，看哪把武器一件都没有。

卡 5：导出客户版

账户下拉（全部账户 / 单个）+「不筛选（全量）」开关 → 「导出客户版」。

  • 默认只收录台账里用到的武器材料，库存里无关的饰品不进表；勾「不筛选」就全量导出。
  • 生成 输出\库存\库存记录_客户版.xlsx：三色表头（绿=可改 / 灰=程序内部别动 / 深蓝=自动行情）、冻结首行 + 筛选、附「使用说明」sheet。
  • 列与主存储一字不差：客户改完改名回 库存记录.xlsx 就能继续增量同步。
  • 你手工加的行（assetid 留空）永远保留；台账读取失败时自动退回全量。
  • 发客户前可以把多余账户 sheet 删掉。

卡 6：输出目录

自带文件浏览器，输出\库存\ 下的文件直接看：目录点「进入」，文件可「下载」或「打开」（调系统默认程序）。生成完文件找不到，就先来这里。

直接编辑 库存记录.xlsx 的注意

  • 一个 sheet = 一个账户；「备注」列随便写，同步永不覆盖。
  • 加手工行（别的平台/线下买的）：自己加一行，物品名照台账写法填，assetid 列留空 → 永远保留。
  • 改名 / 改备注以你改的为准；该件卖出后下次同步自动删行。
  • 编辑时先别跑同步（Excel 占着文件会失败），存盘关掉再同步。
  • 程序写的 assetid 别动、也别手填数字（会显示成乱码）。

3.5 开炉工具

卡 1：配料寻优（这炉怎么配）

  1. 选账户 → 点「开始寻优」。
  2. 默认会先自动同步一次该账户库存（联网，慢）；想快点、用上次快照，就勾「跳过前置扫描（直接用现有快照）」。
  3. 跑完看日志：逐炉列出 10 把具体拿哪些件、磨损怎么分配；凑不满/凑不齐的直接标缺。
  4. 炉单同时落盘：输出\配料寻优_炉单_号<账户>.json（留档）+ 配料寻优_炉单.json（最近一次）。

纪念品材料默认纳入，普通/纪念品可同炉，暗金（StatTrak）不参与。

卡 2：主材料调价（主价改了，重算副价）

  1. 「组号」填 2:1 2:4 这样（账号:组号，空格分隔，可多个）。
  2. 「乘数」填主材料价格倍数，如 1.13；「买入乘数」可空——空 = 台账「买入」那列不动，只重算副价；填了（如 1.13）则买入价也同步乘上去。
  3. 点「① 预览（dry-run，不写入）」→ 看日志里每行的原副价 / 新副价 / 余量变化。

  4. 确认没问题，才点「② 正式执行（写入台账）」→ 弹确认 → 确定。

  5. 任何一行余量会超出 0~0.15 时自动中止不写，日志会指出是哪一行。

  6. 跑之前关掉 Excel（台账被占用会中止）。

卡 3：自动开炉（Beta）

⚠️ 注意先读这段：自动开炉直接操作你的 Steam 账号执行汰换合同，不可逆（10 件材料炼掉就无法恢复），且 Steam 自动化属灰色地带，账号风控风险自担。只开「配料寻优」刚排出来的炉。Beta 期间有问题联系作者 QQ 916182191。

用法（三道闸，一步都不能跳）：

  1. 「查看炉单」：列出最近一次炉单——生成时间、账号、共几炉、每炉什么内容。令牌自动跟随炉单上的账户，不会用错号。
  2. 填炉号 → 「预演（不发请求）」：连 Steam 读实时库存，逐件校验（品质可炼 / 磨损与炉单一致 / 不在保护期 / 无重复 / 件数 = 10），列出这 10 件具体是哪几件。任何一项不过就中止，不会发请求。
  3. 预演通过后，在「键入炉号确认」框再键入一次炉号，才解锁「真开炉」按钮；点击后还有一次弹窗确认。
  4. 真开时程序发请求前会重新连 GC 重校验一遍——预演之后库存变过的炉（比如材料被送走了）会被自动拦下。被拦是保护你，不是 bug。
  5. 开完看产物：页面日志 + 输出\steam\开炉记录_累计.json（每炉一条，含产物与消耗，供对账）。

前置条件：该账户已在「库存记录」页完成过 Steam 登录（有令牌）。令牌过期就重新登录一次。

开炉时报 LoggedInElsewhere？ 这个号正在别处登录 Steam（电脑客户端 / 手机）。开炉用的会话要求"独占"，把其它设备的 Steam 退掉再试。

卡 1：账户与凭据

四、常见问题

  1. 提示 BUFF Cookie 未配置 / 失效 —— 「配置管理」→ 该账户「编辑」→ 重贴 Cookie → 保存；表格 BUFF 列显示「可用」才算好（抓法见 2.2）。
  2. 「没有利润率 > X 的达标配方」 —— 门槛太高，降到 0.5 再看；或多加几个收藏品编号。
  3. 提示磨损绑定校验失败 —— 产物归一化磨损要≈ 10 把材料磨损的平均值，检查「产物归一化磨损」那一项。
  4. BUFF 报风控 / 请求频繁 —— 等几分钟再跑，编号多可分批；程序自己也会放慢重试。
  5. 查询 / 缺料提示「库存未扫描」 —— 先去「库存记录」页做一次 Steam 同步。
  6. 双击 exe 窗口一闪而过 —— 正常都会停住等你回车；闪退说明同级缺 爬虫配置.json，放回来即可。
  7. 杀毒软件误报 —— PyInstaller 打包的常见误报，加信任即可。
  8. 收不到邮件 —— 依次查：首页「发信配置」是否就绪；「配置管理」的授权码是不是「邮箱生成的授权码」而不是登录密码；SMTP 服务器与邮箱是否匹配（163 必须 smtp.163.com）；两个邮件开关是否被关。
  9. 邮件提示认证失败（535） —— QQ / 163 都要先开启 SMTP 服务才能用授权码登录，回邮箱确认服务是「已开启」、授权码是新生成的。
  10. 想确认订阅是否正常 —— 看顶栏右侧状态条，或进「订阅管理」看状态 / 到期 / 剩余次数。
  11. 想看上次扫描 / 校验是什么时候 —— 「材料邮件提醒」页，「价格提醒设置」「期望校验」两张卡底部各有一行。
  12. 提醒跑得太频繁 / 太稀疏 —— 别在计划任务里硬限频率：去「价格提醒设置」改「扫描间隔」或「每天运行时刻」（期望校验同理）。任务触发再高频，程序自己会跳过。
  13. 台账加了新账户 sheet，邮件没发到对应客户 —— 三处对齐：账户名 = 台账 sheet 名 = 按账户分发的键，一字不差。
  14. 换了电脑 —— 拷整个文件夹 → 重新激活（订阅管理）→ Cookie / 邮箱配置跟着 爬虫配置.json 一起过去。
  15. GitHub 仓库里怎么只有一个「实时炼金配方_模板」 —— 真实台账含个人持仓，特意不入库；模板就是拿来照着填的，第 2 个 sheet「填写说明」有 18 列与子块规则的完整解释。
  16. 配料寻优提示缺库存文件 —— 先在「库存记录」页同步一次（正常情况寻优会自己先同步，出现本提示一般是同步失败了，看日志）。
  17. 主材料调价中止 / 失败 —— 两个常见原因：台账被 Excel 打开（关掉重试）；重算后某行余量会超出 0~0.15（程序自带保护，日志会指出哪一行）。
  18. 提示找不到 数据源\ —— 这个目录不能删 / 移 / 改名；丢了就重新解压一份完整包，把它拷回 exe 同级。
  19. Steam 令牌验证器总提示「重取验证码」 —— 动态码 30 秒一换：看到输入框出现后尽快取码填入；提示不对就重取一个新的再提交。
  20. 扫码登录等不到二维码 —— 约 3~5 秒出现（图落在 steam_probe\登录二维码.png）；一直不出现就看黑窗口里 node 的报错（装了 Steam++ 加速器会自动降级重试，不影响）。
  21. Steam 同步提示「找不到库存文件」 —— 先在「库存记录」页做一次令牌验证器登录（成功后会把 steamID 记进 爬虫配置.json），再点同步。
  22. Steam 换号 / 登录失效 —— 「库存记录」页点「重新登录」，或用卡片底部「扫码登录（备用）」。
  23. 不想登录 Steam / 手机没装 App —— 用 BUFF Cookie 通道同步库存（命令行，附录 A 第一条）；两条通道写同一张 库存记录.xlsx，随时混用。
  24. 浏览器打不开 / 白屏 / 提示「服务连接失败」 —— 黑窗口被关了，重新双击 exe；还不行就看黑窗口打印的实际端口，手动访问 http://127.0.0.1:端口/。
  25. 同一任务点了没反应 / 提示「正在运行中」 —— 上一个还没跑完，等它结束或点任务面板右上「停止」。
  26. 改完页面没生效 —— 配置类改动要点对应卡片的「保存」按钮；web\ 里的界面文件改过的话，按 Ctrl + F5 强刷。

附录 B 计划任务（想全自动时看）

页面里的「每天运行时刻」只是记录该跑的时间点，真正到点触发要靠系统计划任务。以「每 10 分钟看一眼、但按设置节流」为例：

  1. Win + S 搜 任务计划程序，打开。
  2. 右侧点 创建基本任务。
  3. 名称填 BUFF降价提醒 → 下一步。
  4. 触发器选 每天 → 下一步，随便设个起始时间（后面再改）。
  5. 操作选 启动程序 → 下一步。
  6. 三项填法：
  7. 程序：浏览选到 BuffToolkit.exe
  8. 参数：--price
  9. 起始位置：选 BuffToolkit.exe 所在文件夹
  10. 完成后，任务列表里右键该任务 → 属性 → 「触发器」→ 编辑 → 勾「重复任务间隔」10 分钟，持续时间「无限期」。
  11. 想同时做期望校验，同法再建一个，参数换 --expect。

搭配建议

  • 触发频率设得比间隔高没关系：程序按「扫描间隔」或「每天运行时刻」自己判断跑不跑，不会重复发信。
  • 想立刻强跑一次：参数加 --force。
  • 每次运行结果看 日志\ 下对应目录的最新文件。
  • 计划任务跑的时候不需要浏览器，但需要程序目录完整（数据源\、node\、steam_probe\ 都在）。
